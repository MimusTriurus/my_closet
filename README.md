# YourCloset — HTML/CSS/JS прототип

Прототип виртуального гардероба по мотивам приложения [yourclosetapp.com](https://www.yourclosetapp.com/).
Без сборки и без бэкенда: чистые ES-модули, IndexedDB, Canvas, Konva, ML-модель удаления фона в браузере.

## Запуск

Нужен локальный сервер (камера и ES-модули не работают по `file://`):

```bash
python dev-server.py 8123
```

Открыть http://localhost:8123 — удобнее в мобильном режиме DevTools (375×812).

Первый запуск: гардероб пуст. Вещи добавляются кнопкой **+** на вкладке «Гардероб» —
по одной (сразу с вырезанием фона) или пачкой до 10 снимков, которые ложатся
в категорию «Сортировка» и разбираются позже. В `samples/` лежат 10 фотографий
для проверок.

## Что реализовано

| Функция оригинала | Где в прототипе |
|---|---|
| Фото вещи камерой / из галереи | `capture.js` — `getUserMedia` и file input |
| Автоудаление фона (ИИ) | `editor.js` — `@imgly/background-removal` (ONNX+WASM, ~40 МБ при первом запуске) |
| Tap Background | «Палочка» — flood fill по клику с настройкой чувствительности |
| Rectangular Crop / Freestyle Crop / Erase manually | «Кроп», «Лассо», «Ластик» + «Вернуть» (восстановление стёртого) и «Отменить» |
| Фон карточки вещи и фон образа | `bgs.js` — 12 фонов, включая градиенты |
| Категории и подкатегории, свои категории | `closet.js` — менеджер категорий, счётчики вещей |
| Сортировка | новые / старые / по названию / по цвету (по тону в OKLab) |
| See the colors in your closet | палитра строится из реальных цветов гардероба |
| Search by color / Scan color with camera | `color.js` + пипетка с камеры (📷 слева от палитры) |
| Комбинированный фильтр «категория + цвет» | чипсы категорий + свотчи цвета работают вместе |
| Create outfits: Move / Resize / Rotate | `outfits.js` — холст на Konva, трансформер, слои «выше/ниже» |
| Style Book / коллекции | коллекции образов, фильтр по коллекции |
| Рандомизация образа | 🎲 «Случайно» — по одной вещи из трёх случайных категорий |
| Calendar, превью месяца, счётчики | `calendar.js` — образы и отдельные вещи на день |
| Packing | `packing.js` — поездки со списком и отметками «уложено» |
| Backup / restore | `settings.js` — экспорт и импорт всего гардероба одним JSON |
| Массовое добавление | до 10 снимков за раз в служебную категорию «Сортировка» |

## Архитектура

```
index.html          оболочка: топбар, 5 вкладок, таббар, модалки
css/style.css       мобильный layout (макс. 480px), токены темы
js/app.js           роутинг вкладок, перерисовка по событию state
js/db.js            обёртка над IndexedDB (картинки как Blob)
js/state.js         состояние + персистентность + CRUD
js/ui.js            h(), модалки, тосты, диалоги
js/color.js         палитра вещи, OKLab, сравнение цветов
js/editor.js        редактор фото: ИИ + палочка + ластик + кроп + лассо
js/capture.js       камера, галерея, пипетка цвета
js/closet.js        вкладка «Гардероб»
js/outfits.js       вкладка «Образы» + редактор образа (Konva)
js/calendar.js      вкладка «Календарь»
js/packing.js       вкладка «Чемодан»
js/settings.js      резервная копия (экспорт/импорт JSON)
js/picker.js        выбор вещей/образов
js/bgs.js           палитра фонов
fonts/              Manrope и Cormorant Garamond (лежат локально, не с CDN)
vendor/konva.min.js редактор образов (тоже локально)
samples/            10 фотографий вещей для тестов
```

Данные хранятся только в браузере (IndexedDB, база `yourcloset`). Очистка данных сайта удалит
гардероб — для переноса используйте экспорт в файл.

## Ограничения прототипа

- ИИ-модель качается с CDN при первом нажатии «ИИ-фон» (~40 МБ), затем кэшируется браузером.
  Без сети работают только ручные инструменты.
- Backup — файл вместо Google Drive; формат тот же по смыслу.
- Приложение не открывается без сети: нужен сервис-воркер (PWA). Шрифты и Konva
  уже локальные, остаётся только ИИ-модель.
- Синхронизации между устройствами нет.
